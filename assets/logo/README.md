# XY107 logo

Matches the website header wordmark: DM Sans, `xy` at weight 750, `107` at weight 350, letter-spacing `-3px` at `34px`, ink `#21314a`, paper `#f3f5f8`. Outlines are in the SVG files, so these do not require the font to render.

| File | Use |
| --- | --- |
| `wordmark.svg`, `wordmark.png` | Horizontal logo on light backgrounds (site, README, docs) |
| `wordmark-white.svg`, `wordmark-white.png` | Horizontal logo on dark backgrounds |
| `icon.svg`, `icon.png` | GitHub and X avatars (square, light). `icon.png` is 1024px |
| `icon-dark.svg`, `icon-dark.png` | Square avatar on dark |
| `icon-512.png` | 512px square, same lockup as `icon.png` |
| `favicon.svg`, `favicon-32.png` | Browser tab |
| `apple-touch-icon.png` | iOS home screen, 180px |
| `og.svg`, `og.png` | Link previews (1200x630) |

Upload `icon.png` as the X and GitHub profile photo. The wordmark is inset so a circular crop still clears the type.
