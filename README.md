# 关于我，以及这个项目的由来

我是一名 2025 年毕业的中国普通一本大学生，父母是年近六十的下岗农民工。

两个月前，我又失业了。这是大学毕业以来的第四次，如果算上实习，是第五次。

从大四开始实习，到现在两年的时间，我投了上千份简历，面试了上百次，得到过五次工作机会，其中一次来自校招。每一次入职，我都希望自己能留下来。但这五份工作，无一例外，都在转正前以裁员结束了。

三次，公司给了我半个月工资的赔偿；另外两次，没有任何赔偿。给出的理由大同小异，不是 AI，就是业务调整。

最初，我总是先从自己身上找原因。我甚至觉得，自己还在试用期，算不上“正式员工”，离开好像也是理所当然的。公司说是业务调整，我却想，也许只是我能力不够，HR 给了一个不那么伤人的理由。

于是接受，再重新开始。想着下一份工作也许会好一点，至少，能让我做过试用期。

这样的事重复了几次以后，我开始害怕下一次重新开始。以前还能用来鼓励自己的话，后来自己也不太信了。我依然想找到工作，只是越来越难相信，努力之后就能慢慢安定下来。

我认识的一些同届同学、师兄师姐，也有类似的经历。知道自己不是唯一一个遇到这些事的人，多少有些安慰，却也让我更迷茫。

眼前最急的，还是生活。

家里没有能力再给我提供经济上的支持。我算过，这两年五份工作加上裁员赔偿，总共挣了六万块左右。我每个月给家里转五百，自己在大城市合租，房租每月六百到八百。因为换工作搬了两次家，再加上日常开支，最后没能存下钱，还需要做兼职才能勉强维持生活。

所以，每次失业之后，我都得继续投简历。很多情绪还没来得及想清楚，就得先想下个月的房租。

---

在这些经历里，AI 也成了一个让我心情复杂的词。

我是一个科幻迷。看小说的时候，我总希望 AI 能更强，发展得更快一些。可当现实中，他却让我感到焦虑迷茫，我很难再带着同样的心情看它。

我知道它很厉害，也想学、想用、想跟上。但有些工具用不起，也用不了；即使开始学，也常常觉得自己追不上它变化的速度。

再回头看学校里学过的东西，会觉得它们和眼前的工作要求隔了很远。接下来该学什么，去哪里学，学到什么程度，才能找到一份能留下来的工作？这些问题，我至今没有答案。

---

最近，我在社交媒体上看到了星宇裁员事件，也看到了围绕这件事的关注和讨论。让我稍微宽慰的是，他们的遭遇被人看见了。

我很敬佩这 107 个学弟学妹。他们有勇气，也想办法采取了行动。看到他们，我会想到自己：刚从学校出来，想找一份工作，挣一点钱，让自己和家里过得好一点，对往后的日子有一点盼头。

从自己和身边人的经历来看，我很难把这当成一件孤立的事。但并不是每个人的遭遇都能被看见，也不是每个人都有余力站出来。

我很难责怪那些沉默的人，我自己也是其中一个。下一份工作在哪里，下个月的房租怎么办，已经足够让人疲惫。就算反抗，大概率也不能改变什么，更多时候只会让自己处于更难堪的境地。很多委屈，就这样咽了下去。

可看到他们之后，我还是有些不甘心。我不希望这些经历最后只剩下简历上几段需要解释的空白，以及面试时又一次对自己能力的怀疑。我想把它们写下来，让看到的人知道，这些事发生过，也确实影响着一些人的生活。

这是我开始做这个项目的原因。

---

最初，我只想梳理星宇事件和自己的经历，发到 GitHub 上，留下一份记录。

一位懂区块链和 Web3 的朋友知道后，和我聊了很多。他建议我给项目创建 X 账号，也提出可以借助区块链，为这些记录留下可查验的痕迹。

于是，我开始学着用钱包，了解区块链，摸索怎样把这些想法实现出来。做的过程中，我有了更多的想法。朋友一边教我，一边和我讨论项目，还资助了 0.05 ETH，用于部署和运维的 Gas 费。对我来说，这些帮助都很实在。这个项目能走到现在，离不开他。

---

写下这些的时候，我已经又开始找工作了。投简历，等回复，面试，下一次试用，也许还有下一次被裁，想办法让生活继续下去。

焦虑失望痛苦还是如影随形。但那一点尚未被消磨的不甘，总算有了一个去处。

“记录，行动，促进好的改变。”我把这句话写进了项目。写下来的时候，我也不知道，会不会有改变，大概率不会。

但至少我以自己的方式把它永久地记录下来了。

谢谢你读到这里。
